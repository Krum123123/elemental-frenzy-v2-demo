# Elemental Frenzy

[Play the demo](https://krum123123.github.io/elemental-frenzy-v2-demo/)

Built static game using demo credits with no real-money value. Original artwork was made for this project. Original procedural audio is dedicated to CC0 1.0.

RTP 96% (91%-101%) and payout frequency 40% (35%-45%) are unverified targets, not measured, certified, or guaranteed. No balance simulations were run.
